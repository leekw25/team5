# 멘토 셋업 가이드 (1일차 전)

코드는 이미 준비돼 있습니다. 멘토가 할 일은 아래 클릭과 붙여넣기입니다. 위에서부터 순서대로 하세요.

## 1. 코드를 GitHub에 올리기

완료(저장소: https://github.com/leekw25/team5).

## 2. GitHub 설정 (저장소 Settings 화면)

1. **Collaborators** → 개발자 A, B의 GitHub 아이디 초대
2. **Branches** → Add branch ruleset(또는 Add rule), 대상 `main`
   - Require a pull request before merging ✅
     - Require approvals: 1 ✅
     - Require review from Code Owners ✅
   - Require status checks to pass ✅ → `check` 선택(첫 PR이 한 번 돌아야 목록에 나옴)
   - Block force pushes ✅
3. **General → Pull Requests** → Allow squash merging만 켜 두기

## 3. Supabase 설정 (대시보드)

1. **SQL Editor** → New query → `supabase/migrations/20261006000000_init.sql` 내용을 통째로 붙여넣고 **Run**
2. **Authentication → Sign In / Providers** → Email 켜짐 확인, **Allow new users to sign up 끄기**
   - 앱에 넣는 anon 키는 공개된 값이라, 가입을 막아 두어야 모르는 사람이 계정을 만들지 못합니다.
3. **Authentication → Users → Add user → Create new user** (Auto Confirm 체크)로 3개 만들기
   - `demo@fitlog.app` (시연용)
   - 개발자 A용, 개발자 B용 (각자 개발할 때 데이터가 섞이지 않게)
4. **SQL Editor**에서 `supabase/demo/reset-demo.sql` 실행 → 오류 없이 끝나면 시연 데이터가 들어감
   - 리허설과 발표 직전마다 다시 실행합니다.
5. **Project Settings → API**에서 Project URL과 anon(또는 publishable) 키를 복사해 둡니다.
   - `service_role` / `secret` 키는 절대 공유하지 않습니다.

## 4. Gemini API 키

1. [Google AI Studio](https://aistudio.google.com) → Get API key → Create API key
2. 키는 **앱 설정 화면에 붙여넣는 용도로만** 씁니다. 코드, .env, 카톡·슬랙에 남기지 않습니다.
3. 결제를 연결했다면 Google Cloud 콘솔에서 예산 알림을 걸어 둡니다.
4. 개발자 A·B는 각자 자기 키를 발급받아 쓰는 것을 권장합니다(한 명 키가 막혀도 다른 사람은 계속 개발).

## 5. 각자 PC에서 앱 띄우기 (멘토 먼저, 1일차에 A·B와 함께)

1. 준비물: Node.js 24, Git(또는 GitHub Desktop), 휴대폰에 Expo Go 앱
2. 저장소를 받은 폴더에서
   ```bash
   npm install
   ```
3. `.env.example`을 복사해 `.env`를 만들고 값 채우기(Supabase URL·anon 키, 3-③의 본인 계정)
4. 실행
   ```bash
   npx expo start
   ```
5. 휴대폰 카메라(iPhone) 또는 Expo Go(Android)로 QR 찍기
   - 안 열리면 노트북과 휴대폰을 같은 와이파이·핫스팟에 연결하거나 `npx expo start --tunnel`
6. 앱의 **설정 →** 화면에서 Gemini 키 입력 → "저장됨 ✅"이 나오면 준비 완료
