- [x] 테이블·뷰·RLS 적용(마이그레이션 `20261006000000` 적용 완료, 보안·성능 점검 경고 0건)

## 4. Gemini API 키

1. [Google AI Studio](https://aistudio.google.com) → Get API key → Create API key
2. 키는 **앱 설정 화면에 붙여넣는 용도로만** 씁니다. 코드, .env, 카톡·슬랙에 남기지 않습니다.
3. 결제를 연결했다면 Google Cloud 콘솔에서 예산 알림을 걸어 둡니다.
4. 개발자 A·B는 각자 자기 키를 발급받아 쓰는 것을 권장합니다(한 명 키가 막혀도 다른 사람은 계속 개발).

## 5. 각자 PC에서 앱 띄우기 (멘토 먼저, 1일차에 A·B와 함께)

1. 준비물: Node.js 24, Git(또는 GitHub Desktop), 휴대폰에 Expo Go 앱
2. 저장소를 받은 폴더에서
   ```bash
   npm install
   ```
3. `.env.example`을 복사해 `.env`를 만들고 값 채우기(Supabase URL·anon 키, 3-③의 본인 계정)
4. 실행
   ```bash
   npx expo start
   ```
5. 휴대폰 카메라(iPhone) 또는 Expo Go(Android)로 QR 찍기
   - 안 열리면 노트북과 휴대폰을 같은 와이파이·핫스팟에 연결하거나 `npx expo start --tunnel`
6. 앱의 **설정 →** 화면에서 Gemini 키 입력 → "저장됨 ✅"이 나오면 준비 완료
