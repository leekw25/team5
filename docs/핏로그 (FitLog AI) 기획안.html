핏로그FitLog AI

말 한마디, 사진 한 장으로 끝내는 미션 중심 AI 건강 다이어리

기록은 최소화하고 성취감은 극대화하는 헬스케어 앱입니다. AI의 멀티모달 분석(음성·사진 인식)과 게이미피케이션(달력 채우기 리워드)을 결합했습니다.

② 오늘의 건강 미션 + ④ 쉬운 입력 식단·운동 도우미

1기획 배경 및 핵심 컨셉

지금의 문제

기존 식단·운동 앱
칼로리와 무게를 일일이 검색해 입력해야 해서 3일을 넘기기 어렵습니다.
기존 미션 앱
단순 체크리스트에 그쳐 실제 영양·운동 분석이 부족합니다.

핏로그의 해결 방식

  1. 쉬운 입력음성이나 사진 한 장으로 식단과 운동을 3초 만에 기록합니다.
  2. 오늘의 미션AI 분석을 바탕으로 당일 수행 가능한 맞춤형 미션을 제안합니다.
  3. 성취감 리워드미션을 완수하면 달력이 시각적으로 채워지며 습관 형성을 유도합니다.

전날 기록은 다음 날 아침 미션 추천에 다시 반영됩니다.

2핵심 기능

① 초간편 AI 기록

음성·텍스트 자유 입력평소 말하듯 음성이나 텍스트로 입력하면 AI가 음식명, 칼로리, 영양소, 운동 부위, 소모 칼로리를 자동으로 파싱해 기록합니다.

사진 한 장 식단 분석음식 사진을 찍으면 GPT-4o Vision이 메뉴를 인식하고 예상 영양 성분 비율(탄·단·지)을 자동 산출합니다.

“점심에 제육볶음 반 공기랑 된장찌개 먹었어”

  • 음식명

  • 영양소
“스쿼트 15개 3세트 함”
AI 자동 파싱

② AI 맞춤형 오늘의 미션 3종 세트

매일 아침 사용자 상태와 전날 기록을 바탕으로 고를 수 있는 카드형 미션 3개를 제시합니다.

미션 자동 달성 체크식단과 운동을 기록하면 AI가 판단해 미션 성공 여부를 자동으로 체크합니다.

③ 리워드와 인터랙티브 달력

달력 스탬프
미션을 완수하면 달력의 해당 날짜가 캐릭터 스탬프나 색상 오버레이로 채워집니다.
연속 달성 스트릭
연속으로 미션에 성공하면 애니메이션 효과와 함께 특별 리워드 배지를 지급합니다.

④ AI 1줄 코칭

하루 기록과 미션 성공 여부를 바탕으로 AI가 친근한 톤으로 칭찬, 격려, 피드백을 담은 1줄 총평을 줍니다.

오늘 단백질 목표를 달성하셨네요! 저녁 튀김 참기 미션까지 성공해서 완벽한 하루입니다. 🔥

Backend & DB

AI API

자연어 텍스트와 음성 변환 텍스트 파싱, 오늘의 미션 생성, 1줄 피드백 작성
GPT-4o Vision
식단 이미지 분석
Whisper API
음성 입력을 텍스트로 실시간 변환

기록이 스탬프가 되기까지

  1. 입력음성 또는 사진
  2. 인식Whisper가 음성을 텍스트로, Vision이 사진을 메뉴로
  3. 파싱GPT-4o가 음식·운동, 칼로리, 영양소로 구조화
  4. 저장Supabase 또는 Firebase
  5. 판정오늘의 미션 성공 여부 자동 체크
  6. 리워드달력 스탬프와 1줄 코칭

5발표 시연 시나리오 (3분)

발표 현장에서 청중의 호응을 이끌어내기 위한 3분 데모 흐름입니다.

기존 앱은 사과 1개 칼로리를 찾아 입력하는 데 1분이 걸리지만, 핏로그는 사진을 찍거나 “아침에 사과 반 개랑 계란 2개 먹었어”라고 말하면 2초 만에 분석이 끝납니다.

    결과메인 화면의 오늘 날짜 달력 칸이 캐릭터 스탬프로 채워집니다.
