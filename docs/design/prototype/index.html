핏로그 디자인 프로토타입

Stitch로 만든 6개 화면에 스크롤·성공 모션을 입혔습니다. 휴대폰 크기(375px)로 보면 가장 정확합니다.

01

온보딩 랜딩

스크롤하면 섹션·카드가 차례로 올라옵니다

 02

오늘 홈

마이크를 누르면 시연 흐름: 듣는 중 → 단백질 채움 → 폭죽

 03

음성 기록 결과

‘저장하기’ → 축하 화면

 04

미션 성공 축하

열리자마자 파랑·노랑 폭죽, 일러스트 스탬프

 05

리워드 달력

진행 링 채움, 완수일 스탬프가 차례로 쿵

 06

설정

Gemini API 키 입력

적용한 모션 (awesome-ai-motion 카드 기본값)

효과어디에값
stagger 리빌모든 화면의 카드·제목·문단·이미지0.06s 간격, 0.55s, 24px 위로
bar-grow미션 진행률 막대1.05s, power2.out

‘동작 줄이기’(prefers-reduced-motion)를 켠 기기에서는 모든 모션이 꺼지고 완성 상태로 바로 보입니다. 앱(Expo)으로 옮길 때는 같은 값으로 react-native-reanimated를 쓰면 됩니다.
